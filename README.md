# gandla-vyshnavi-portfolio
## Overview
This task is a responsive personal portfolio website developed using HTML and CSS. The website presents personal, academic, and professional information in a clean and modern layout.
## Technologies Used
- HTML5
- CSS3
## Skills
- Responsive Web Design
- UI/UX Design
- Layout Alignment
- Flexbox
- CSS Grid
- Icon Integration
- Hover Effects & Animations
- Mobile Responsive Styling
## Features
- Responsive modern interface
- Fixed navigation bar
- Hero section with custom logo
- About section with skills and education
- Experience and internship section
- Project showcase with GitHub links
- Certifications section
- Contact form with validation
- Smooth scrolling effects
## Modules Included
### Home Section
Displays introduction, role, buttons, and social links.
### About Section
Contains profile summary, technical skills, and educational background.
### Experience Section
Showcases internship experiences and technical exposure.
### Projects Section
Displays project details with descriptions and repository links.
### Certifications Section
Lists completed certifications and learning achievements.
### Contact Section
Provides contact details and a message form.
